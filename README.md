# Run and deploy your AI Studio app

View your app in AI Studio: https://ai.studio/apps/be53cab0-ce2e-4905-a81e-3e005ba4fe3e

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app (analysis uses the shared Bold Studio Gemini proxy; this app does not need its own API key):
   `npm run dev`
